## Points for the reviewer

- **Case.** New strings use "expediente" (es-ES) and "dossier" (fr-FR), including the agent names "Agente de Expediente" and "Agent de Dossier". Older homepage strings not listed below still use "casos" and "cas". Choose one term per language.
- **Co-designer.** The glossary treats it as a product name, so the strings below no longer use "Co-diseñador" or "Co-concepteur".
- **Records.** The diagram label keeps the existing "Registros" and "Enregistrements". pt-PT now uses "Gestão documental", so check whether "Gestión documental" and "Gestion documentaire" fit better.
- **Scope.** The table lists only the strings written in the 2026-11-06 homepage update. All other es-ES and fr-FR strings in `index.html` also need review before publishing.
